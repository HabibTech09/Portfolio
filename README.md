## 🛠️ Featured Projects

### 1. Nigerian Food Commodity Price Monitoring and Alert System

**Category:** AI Automation | Workflow Automation | Data Monitoring

I built an AI-powered automation agent using **n8n** to monitor daily price changes in Nigerian food commodities and deliver automated summaries through Telegram.

**Key features:**
- Monitors daily food commodity price information.
- Tracks changes in commodity prices.
- Generates automated daily summaries.
- Sends price update alerts directly to Telegram.
- Reduces the need for repetitive manual monitoring.

**Project objective:** To make food commodity price information easier to monitor and access through automated reporting and notifications.

### 2. Community Disease Outbreak Surveillance and Alert System

**Category:** Hackathon Project | Data Collection | Public Health Technology

I participated in a hackathon where our team developed a system designed to collect information on potential disease outbreaks within a community and send real-time alerts to relevant stakeholders.

**Key features:**
- Collection of community-level disease surveillance information.
- Identification and reporting of potential outbreak signals.
- Real-time alert notifications to relevant stakeholders.

**Project objective:** To demonstrate how technology and timely information sharing can support community disease surveillance and public health response.

*This was a collaborative hackathon project.*

**Category:** Data Cleaning | Statistical Analysis | Research Data

**Key activities:**

### 4. AI-Powered Student Learning Progress Analysis and Feedback System

**Category:** AI Automation | Educational Technology | Data Analysis

I developed an AI-powered data analysis and automation workflow using Google AI automation tools. The system receives students' learning progress data, performs automated weekly analysis and generates personalized feedback with recommendations based on individual performance.

**Key features:**
- Receives students' learning progress information.
- Performs automated weekly data analysis.
- Evaluates individual student performance.
- Generates personalized feedback.
- Provides recommendations based on students' learning progress.

**Project objective:** To demonstrate how AI and data automation can support personalized learning, performance monitoring and timely educational feedback.
